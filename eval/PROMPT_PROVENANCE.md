# Evaluation Prompt Provenance

`eval/eval_prompt.txt` contains one text prompt per line for PixelRush evaluation.

The prompts were prepared from public LAION-Aesthetics-style image-text metadata/captions:

```text
https://laion.ai/blog/laion-aesthetics/
```

This file contains prompt text only. It does not include images, image URLs, model checkpoints, embeddings, or training data.
